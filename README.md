# Tail Jumper (working title)

Аркадный вертикальный джампер:

– персонаж прыгает по платформам
– платформы разлетаются партиклами
– партиклы летят в хвост
– хвост растёт, расцветает и становится ёбаным павлином
– при падении хвост растворяется
– игра — про кайф, флоу и визуал

Это прототип, цель — получить ощущение:
«Хочу прыгать дальше только ради визуального оргазма хвоста».

# Запуск

- `index.html` — обычная игра (без редактора).
- `debug.html` — редактор (Tail Viewer + генератор платформ, открыты сразу).
- `runw.bat` — Windows-скрипт: поднимает локальный сервер и открывает игру.
- `runwd.bat` — Windows-скрипт: поднимает локальный сервер и открывает редактор.
