## Rendering & Viewport

Игра должна рендериться в канвас фиксированного aspect ratio (например 9:16).

Правила:
- Canvas по высоте = 100% доступной высоты окна/экрана
- Ширина вычисляется исходя из aspect ratio
- Canvas центрируется по горизонтали
- Никаких резиновых растяжений

Внутри движка:
- игра использует "виртуальное разрешение"
- реальный вывод = масштабированная версия
- все инпуты (мышь/тач) преобразуются в виртуальные координаты

## Current Implementation

- Статичный браузерный билд без зависимостей: `index.html`, `main.js`, `config.js`, `style.css`.
- Весь тюнинг хранится в `config.js` (физика, платформы, хвост, партиклы, параллакс, аудио, сложность).
- Канвас масштабируется по высоте окна, ширина считается из виртуального размера и scale.
- Инпут переводится в виртуальные координаты через bounding box + scale.

## Как запускать

### Вариант 1: просто открыть
Открой `index.html` в браузере.

### Вариант 2: локальный сервер (рекомендуется)
```bash
python -m http.server 8000
```
Затем открыть: http://localhost:8000
