# AUDIO

– звуки по событиям
– файлы ищутся по названию события
– рандом если несколько
– тихо если файлов нет

Codex документирует.

## Реализация

- Аудио опционально и не блокирует запуск игры.
- Включение происходит после первого клика/тапа (ограничения браузеров).
- Путь к файлам указывается в `config.js`.
- Текущее расположение ассетов: `assets/audio/`.
