# DEVELOPMENT ROADMAP

Правило этапов:

Этап = состояние игры, которое:
- можно запустить в браузере
- даёт новую пользовательскую ценность
- можно визуально и тактильно проверить
- не является внутренней технической заготовкой

Внутренние системы без видимого результата этапом не считаются.

---

## Stage S1 — Base Jump Game (Playable Core)

**Ценность для игрока:**  
Игра запускается. Есть персонаж. Он управляется и прыгает по платформам.

Что должно быть:
- игра открывается по ссылке
- виден персонаж (шарик / смайлик)
- управление:
  - влево / вправо — мышь или палец
  - клик / тап — прыжок
- есть платформы
- персонаж прыгает от платформ
- есть гравитация и падение
- есть земля внизу
- при падении на землю — рестарт

Что можно проверить:
- управление ощущается
- можно прыгать несколько раз подряд
- игра не ломается

❗ Без хвоста, без партиклов, без эффектов — только **чистая механика прыжка**.

---

## Stage S2 — Destruction & Feedback

**Ценность для игрока:**  
Прыжки начинают ощущаться “вкусно”.

Добавляется:
- платформы разрушаются при прыжке
- простые визуальные эффекты разрушения
- базовый звук прыжка / разрушения (если есть ассеты)
- ощущение “я что-то ломаю и лечу дальше”

Проверка:
- прыжок ≠ просто отскок
- есть визуальный и/или звуковой отклик
- играть приятнее, чем в S1

---

## Stage S3 — Tail v1 (Visual Progression)

**Ценность для игрока:**  
Появляется хвост. Видно, что прогресс есть.

Добавляется:
- базовый хвост (партикловый след)
- хвост растёт по мере успешных прыжков
- хвост повторяет траекторию движения
- при падении хвост начинает исчезать
- на земле хвоста нет

Проверка:
- визуально видно рост хвоста
- падение ощущается как потеря
- хочется “прыгнуть ещё раз, чтобы снова отрастить”

---

## Stage S4 — Color & Platform Influence

**Ценность для игрока:**  
Хвост становится разнообразным и живым.

Добавляется:
- платформы разных цветов
- цвет платформ влияет на хвост
- хвост может быть многоцветным
- появляются редкие / яркие платформы

Проверка:
- цвет хвоста реально меняется
- есть ощущение “я собрал что-то особенное”
- визуал стал богаче, чем в S3

---

## Stage S5 — Depth & Parallax

**Ценность для игрока:**  
Появляется ощущение пространства и высоты.

Добавляется:
- параллакс фона (минимум 2–3 слоя)
- часть партиклов уходит в глубину
- дальние элементы движутся медленнее
- хвост и эффекты ощущаются объёмнее

Проверка:
- ощущается глубина
- прыжки “вверх” читаются сильнее
- картинка стала кинематографичнее

---

## Stage S6 — Difficulty Modes

**Ценность для игрока:**  
Игра подстраивается под разные типы игроков.

Добавляется:
- режим “мягкий”:
  - при падении могут остаться платформы
  - есть шанс спастись
- режим “хардкор”:
  - при срыве вниз — летим до земли
- переключение режима через конфиг

Проверка:
- режимы реально ощущаются по-разному
- хардкор напряжённый
- мягкий не фрустрирует

---

## Stage S7 — Audio Atmosphere

**Ценность для игрока:**  
Игра перестаёт быть “немой”.

Добавляется:
- фоновый зацикленный трек
- набор эффектов:
  - прыжок
  - разрушение платформ
  - рост хвоста
- система событий звука (Sound.play("event"))

Проверка:
- звук не раздражает
- без ассетов игра не падает
- с ассетами — становится живее

---

## Stage S8 — Polish & Presentation

**Ценность для игрока:**  
Игра выглядит как цельный прототип, который не стыдно показать.

Добавляется:
- финальная настройка баланса
- сглаживание ощущений управления
- аккуратный старт (click to jump)
- стабильная работа resize / scaling
- фиксы очевидных визуальных багов

Проверка:
- можно дать ссылку другому человеку
- человек понимает, что делать
- хочется поиграть ещё минуту

---

## Stage S9 — Experimental / Optional

**Ценность для игрока:**  
Вау-эффекты (по желанию).

Возможные эксперименты:
- PNG-формы для партиклов
- более сложные хвосты
- дополнительные визуальные режимы
- альтернативные темы

Этот этап **не обязателен** и делается только если есть желание.
